# C2-Pay · ระบบเบิกจ่าย C2 Tech

หน้าเว็บ (GitHub Pages) ของระบบเบิกจ่าย · backend อยู่ที่ `C:\dev\c2-pay-firebase` (Cloud Functions codebase `pay`)

## โครงสร้าง
- อยู่ใน Firebase โปรเจกต์เดียวกับ C2-Calendar (`c2-calendar-c088f`) เพื่อใช้ **บัญชี login ชุดเดียวกัน**
- เข้าระบบ: เรียกฟังก์ชัน `login` ของ C2-Calendar → ได้ token → ทุกคำสั่งของ C2-Pay ส่งผ่านฟังก์ชัน `payApi`
- ข้อมูล C2-Pay อยู่ใน collection ที่ขึ้นต้นด้วย `pay_` และไฟล์ใน Storage โฟลเดอร์ `pay/` — หน้าเว็บอ่าน/เขียน Firestore ตรงไม่ได้ (firestore.rules ของ C2-Calendar ปิดไว้อยู่แล้ว)
- สิทธิ์ C2-Pay ตั้งแยกจาก C2-Calendar: Admin / CEO / User / ไม่มีสิทธิ์
  - ค่าเริ่มต้นบัญชีใหม่: staff → User, ceo → CEO, admin → User (Admin ของ C2-Pay ต้องตั้งเองรายคน · ต้องมี Admin อย่างน้อย 1 คน)
- **ผู้ดูแลเลขบัญชี** มีได้คนเดียว: เพิ่ม/แก้เลขบัญชีรับโอนของทุกคนและบัญชีบริษัท · ต้องใส่รหัสผ่านซ้ำ + เหตุผล · มีประวัติที่ลบไม่ได้ · แจ้งเจ้าของบัญชี · Admin คนอื่นเห็นเลขแบบปิดบางส่วน
- **โหมดทดลองใช้**: ผู้ดูแลเลขบัญชีล้างข้อมูลได้ (แบบ A รายการเงิน / แบบ B ทุกอย่าง) ต้องดาวน์โหลดไฟล์สำรองก่อน + พิมพ์ "ล้างข้อมูล C2-Pay" + รหัสผ่าน + รอ 5 วินาที · กด "ปิดโหมดทดลอง" แล้วเมนูนี้หายถาวร

## เริ่มใช้ครั้งแรก
1. deploy backend (ดู README ใน `C:\dev\c2-pay-firebase`)
2. เปิดหน้าเว็บ → admin ของ C2-Calendar คนแรกที่เข้า จะเห็นหน้า "ตั้งค่าเริ่มต้น C2-Pay" → ยืนยันรหัสผ่าน → เป็น Admin + ผู้ดูแลเลขบัญชี
3. ตั้งค่า → ผู้ใช้และเลขบัญชี: ตั้งสิทธิ์ทีมงาน และเพิ่มเลขบัญชีรับโอน
